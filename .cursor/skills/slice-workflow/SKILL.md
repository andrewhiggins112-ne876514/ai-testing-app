# Slice workflow (PM-owned)

1. **Scope** — One ID from `docs/ops/ROADMAP.md`. List out-of-scope.  
2. **Discover** — explorer-cheap or targeted reads (PM/agents — not the human).  
3. **Plan** — architect if multi-file or security-sensitive.  
4. **Implement** — PM edits directly, or delegates implementer / ui-orb (Grok 4.7).  
5. **Verify** — verifier (Composer). Run focused tests.  
6. **Memory** — doc-keeper or `update-memory` skill.  
7. **Land** — commit, push, merge to main when possible.  
8. **Human** — tell them only: `git pull` + how to check the app. Never ask them to paste a coding prompt into another chat.
